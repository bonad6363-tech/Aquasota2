# АКВАСОТА — прототип сайта

Кликабельный frontend-прототип интернет-магазина фильтров для воды. Первый этап: визуальный стиль, структура и пользовательский путь без оплаты и CRM.

## Запуск

Нужны Node.js 20+ и npm.

```bash
cd aquasota
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

Корзина хранится в `localStorage`. Заявки и заказы не отправляются на сервер.

## Страницы

- `/` — главная
- `/katalog` и `/katalog/:category` — каталог и категории
- `/tovar/:slug` — карточка товара
- `/sravnenie` — сравнение Аквасота-1 и Аквасота-2
- `/dostavka-i-oplata`
- `/dokumenty`
- `/o-kompanii`
- `/kontakty`
- `/korzina`
- `/oformlenie-zakaza`
