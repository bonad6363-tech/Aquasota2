# АКВАСОТА 2 — сайт фильтров для воды

Интернет-магазин-прототип бренда **АКВАСОТА** (производитель ООО «АКВАПЛЮС»).  
Стек: React 19, TypeScript, Vite 8, React Router.

Репозиторий: [bonad6363-tech/aquasota2](https://github.com/bonad6363-tech/aquasota2)

## Возможности

- Каталог по категориям: переносные фильтры, магистральные, сменные элементы, аксессуары
- Карточки товаров с галереей, характеристиками, комплектацией и инструкцией
- Корзина и оформление заказа (без онлайн-оплаты; данные в `localStorage`)
- Сравнение Аквасота-1 и Аквасота-2
- Подбор фильтра (квиз), FAQ, консультационная форма (без отправки на сервер)
- Адаптивная вёрстка, деплой на GitHub Pages

## Быстрый старт

Нужны **Node.js 20+** и npm.

```bash
git clone https://github.com/bonad6363-tech/aquasota2.git
cd aquasota2
npm install
npm run dev
```

Сайт откроется на `http://127.0.0.1:5173/` (или следующем свободном порту).

### Скрипты

| Команда | Описание |

## Структура проекта

```
aquasota2/
├── public/                 # Статика и изображения товаров
│   └── images/
├── src/
│   ├── components/         # UI: Header, Logo, ProductCard, …
│   ├── data/               # Каталог, категории, контакты, картинки
│   │   ├── products.ts
│   │   ├── categories.ts
│   │   ├── images.ts
│   │   └── company.ts
│   ├── pages/              # Страницы маршрутов
│   ├── styles/
│   └── App.tsx
├── .github/workflows/      # Деплой GitHub Pages
└── package.json
```

Товары и цены правятся в `src/data/products.ts`.  
Пути к фото — в `src/data/images.ts` (с учётом `base` для GitHub Pages).  
Контакты — в `src/data/company.ts`.

## Деплой на GitHub Pages

При push в `main` срабатывает workflow `.github/workflows/deploy-pages.yml`.

- `base` в Vite: `/aquasota2/` (см. `vite.config.ts`)
- На Pages используется HashRouter (`VITE_HASH_ROUTER=true` в CI)

После первого деплоя сайт будет доступен по адресу:

`https://bonad6363-tech.github.io/aquasota2/`

В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
